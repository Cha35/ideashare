경품 어드민 (ADM-PZ)

기프티콘·실물경품의 등록 → 코드 적재 → 회차 설정 → 당첨자 매핑·관리 운영 도구
기능 ID ADM-PZ 버전 v1.0 플랫폼 BO(Admin) 인앱 연계 WL v1.0 작성일 2026-06-25
PZ-00개요 · 인앱 연계

경품 어드민은 인앱 마이 > 내 지갑 > 보유 경품(WL)에 표시되는 경품 데이터를 생성·운영하는 상위 도구다. 어드민의 출력(당첨자↔경품/코드 매핑)이 곧 인앱 WL의 입력이 된다.

운영 사이클
PZ-01 경품 등록→ PZ-02 코드 적재→ PZ-03 회차 설정→ 서버 배치 추첨→ PZ-04 당첨자 관리→ 인앱 WL 노출
핵심 정책
회차 체계독립 회차 — KBO 직관 티켓 응모와 별개 체계. 비야구/이슈 마켓에도 동일 구조로 확장.
당첨자 선정서버 배치로 실행, 어드민은 결과 확인만. 각주① 어드민 수동 실행 버튼 필요 여부는 추후 논의 — 우선 미배치.
코드 매핑코드 ↔ 당첨자 1:1 매핑. PZ-02에 적재된 코드 N개 = 당첨자 N명에 순차/랜덤 1:1 할당. (중복 지급·누락 구조적 차단)
타입 분기기프티콘 BARCODE / PIN = 코드 매핑 / 실물 PHYSICAL = 코드 없음, 배송지·동의 수집
각주①  당첨자 선정은 서버 배치 작업으로 처리한다. 운영 편의를 위해 어드민에 "추첨 실행" 버튼을 둘지 여부는 미결로 두며, 본 v1.0은 버튼 미배치(배치 자동 실행)를 전제로 설계한다. 수동 실행 요구가 확인되면 PZ-04에 실행 컨트롤을 추가한다.
MVP 범위 — 경품 등록·코드 적재·회차 설정·당첨자 확인/매핑/엑셀 다운로드까지. 추첨 알고리즘 상세(가중치 등), 실물 배송 상태 추적(배송중/완료), 제세공과금 실제 징수 플로우는 본 문서 제외.
PZ-01경품 마스터ADMIN

개별 경품의 "정의" 단위를 등록·관리한다. 회차 설정(PZ-03)에서 이 경품을 선택해 응모에 건다.

등록 항목
경품 IDprize_id · 자동 채번
구분(카테고리)기프티콘 / 실물 등 경품 구분
경품명인앱 노출 상품명 (product_name)
대표 이미지image_url 업로드
경품 가치prize_value (원) — 5만원 초과 시 제세공과금 대상 자동 플래그
지급 방식BARCODE PIN PHYSICAL 택1
유효/마감 기한expire_at — 기프티콘=사용 유효기간 / 실물=신청 마감 기한
이용안내·유의사항caution (인앱 상세 하단 노출)
지급 방식이 PHYSICAL이면 코드 적재(PZ-02) 대상에서 제외되고, 당첨 시 인앱에서 배송지 수집 플로우(WL-03)로 연결된다.

PZ-02코드 일괄 등록 (엑셀)ADMIN

기프티콘 경품에 핀/바코드 넘버를 엑셀로 일괄 업로드한다. 업로드된 코드 수가 곧 해당 경품의 지급 가능 재고다(코드 N개 = 당첨자 N명 가능).

업로드 규칙
대상지급 방식 BARCODE / PIN 경품만. PHYSICAL 제외.
업로드 단위경품(prize_id) 선택 → 해당 경품 코드풀에 누적 적재
중복 검증동일 코드 중복 업로드 시 행 단위 reject + 리포트
상태적재 시 미할당 → 추첨 시 당첨자에 1:1 할당 → 할당됨
엑셀 양식
컬럼필수설명
prize_id필수대상 경품 ID (또는 업로드 화면에서 선택)
code필수바코드 넘버 또는 핀번호
code_pin선택핀번호형 중 별도 비밀번호 운영 시 (인앱 미노출, 운영 보관용)

PZ-03응모 회차 설정ADMIN

독립 회차(round) 단위로 응모를 생성한다. 회차에 경품·당첨자 수·지급 방식을 묶어 세팅한다.

회차 설정 항목
1. 응모 SEQround_seq · 등록 시 자동 채번 (회차 식별키)
2. 응모 이름어드민 내 관리 제목 (round_name)
3. 진행 기간응모 시작 ~ 종료 일시
4. 당첨자 선정 진행일draw_date — 서버 배치 추첨 기준일 각주①
5. 경품 세팅경품(PZ-01 선택) × 당첨자 인원(수량) × 지급 방식 — 복수 경품 등록 가능 (아래 표)
6. 생성 이력created_at / created_by (등록 완료 시각·생성자)
7. 수정 이력updated_at / updated_by (최종 수정 시각·수정자)
경품 세팅 (회차 내 N개)
경품지급 방식당첨자 수량코드 재고(PZ-02)검증
P-1001 [던킨]BARCODE100명198개충분

PZ-04당첨자 관리ADMIN

서버 배치 추첨 결과를 회차별로 확인한다. 당첨자↔경품/코드 1:1 매핑, 실물경품 배송지·제세공과금 동의 여부를 조회하고 엑셀로 내려받는다.

조회 정보
회차 선택round_seq 기준 당첨자 목록 조회
당첨자 ↔ 경품각 당첨자가 어떤 경품에 당첨됐는지
매핑 코드기프티콘 당첨자별 1:1 할당된 바코드/핀번호 (mapped_code_id)
실물 — 배송지5만원 초과 경품 당첨자의 배송지 입력 여부
실물 — 제세공과금제세공과금 납부 동의 여부
엑셀 다운로드회차별 당첨자 + 당첨 정보 전체 내역 다운로드
타입별 표시 컬럼 분기
  • 기프티콘 당첨자 → 매핑 코드(바코드/핀) 컬럼 표시
  • 실물 당첨자 → 배송지 입력 여부 · 제세공과금 동의 여부 컬럼 표시 (5만원 초과 시 강조)
