02

설계 원칙

왜 이 구조로 좁혔는가

정원 고정으로 공정성 확보

인원수가 다르면 평균·합산·상위N 등 무엇을 써도 형평성 시비가 남는다. 5인 고정으로 분모를 통일해 점수 산식을 한 줄로 단순화.

미참여 = 0점, 무임승차 차단

팀 점수를 "참여자 평균"이 아니라 "정원 5 기준 평균"으로 둬 미참여자가 팀에 손해를 준다. "잘하는 사람만 참여" 역설을 구조적으로 제거.

라운드별 노출 → 재방문 루프

전 경기를 한 번에 깔면 원앤던으로 재방문이 죽는다. 그 라운드 경기만 노출하되, 경기 시작 전까지 수정 가능하게 해 리텐션을 만든다.

2축 동기 — 팀 + 개인

팀 랭킹(협력·바이럴)과 팀 내 순위(개인 기여)를 동시에 보상해, 강팀 묻어가기와 혼자만 잘하기를 둘 다 막는다.

03

팀 구성 & 참여 방식 확정

진입은 단 2갈래 — 만들거나, 들어가거나
진입 ①

팀원을 모집할게요

새 팀 생성 + 초대 링크 발급. 친구에게 링크/코드를 공유해 5인을 채운다. 마감까지 미달이면 자동 배정으로 보충(선택).

팀 생성 → 초대 링크 공유 → 친구 가입 → (미달 시) 자동 충원 → 5인 완성
진입 ②

랜덤 팀에 참여할게요

정원이 빈 기존 팀에 자동 배정. 유저는 팀을 고르지 않고, 시스템이 빈자리에 넣어 5인을 맞춘다. 친구가 없어도 즉시 참여.

랜덤 참여 선택 → 대기열 → 빈 팀에 자동 배정 → 팀 확인
항목규칙
팀 정원5인 고정
팀원 모집 채널초대 링크/코드 + 기존 커뮤니티 모집글(신규 탭 개발 없음)
구성 마감 (Lock)32강 1경기 킥오프(6/29 04:00) 시점에 멤버 확정, 이후 변경 불가
자동 충원/배정 시점킥오프 전 일괄 배치 (정원 5 − 현재 인원만큼 채움)
탈퇴가능하되 해당 멤버 점수는 0점 처리 (팀 분모는 5 유지)
개발 메모: 자동 배정은 별도 매칭 알고리즘 없이 선착순 배치 스크립트로 충분(빈 팀에 대기 유저를 순서대로 채움). 성향 매칭·솔로 큐 고도화는 v2.
04

예측 마켓 확정 로직 재활용

토너먼트는 "진출팀" 2택으로 모호함 제거
대상질문 형식비고
토너먼트 (32강~결승) 다음 라운드에 진출할 팀은? (2택) 승/무/패가 아니라 "최종 진출팀". 연장·승부차기까지 가도 올라간 팀이 정답 → 토너먼트 모호함 제거. 정확스코어 보너스는 이번 제외.
노출 방식 라운드별 일괄 오픈 해당 라운드 경기만 노출. 경기 시작 전까지 자유 수정, 킥오프 시 해당 경기 자동 Lock.
마켓 등록: 어드민의 기존 마켓 등록 기능으로 경기를 사전 등록. 결과 입력·정산도 기존 수동 정산 기능 사용.

점수 & 랭킹 산정

개인 점수는 기존 모델 그대로, 팀 점수만 신규

개인 점수 (개인 랭킹전과 동일 · 검증 완료) — 적중 시 기본 100점, 선택률이 낮은(소수가 고른) 항목을 맞힐수록 가점. "남들 안 고른 걸 맞혔다"는 안목을 보상.

180

200
선택률 10% 미만

팀 점수 — 팀원 5인의 누적 점수 합을 정원 5로 나눈 값.

팀 점수 = ( 팀원 5인의 누적 점수 합 ) ÷ 5
예) 팀원 점수 480 · 530 · 350 · 200 · 0 → 합 1,560 ÷ 5 = 312점
미참여자(0점)도 분모 5에 포함 → 참여하지 않으면 팀 평균이 깎인다.
랭킹기준용도
누적 팀 랭킹팀 점수 내림차순팀 보상의 기준 (메인 경쟁)
팀 내 개인 랭킹같은 팀 내 개인 누적 점수 내림차순개인 보상의 기준 (팀 내 기여)
갱신 방식: 실시간 아님. 경기 결과 입력 → 점수 재계산 → 랭킹 갱신 배치로 처리(정확성 우선). 라운드별 미니 랭킹/보상은 이번 제외.

운영 규칙 & 엣지 케이스 기준값 결정 필요

미참여자 처리

예측 0건 멤버는 0점 + 보상 제외. 보상 자격 최소 참여(전체 경기의 N% 이상) 기준값은 회의에서 확정.

동점 처리

팀 동점·팀 내 개인 동점의 tiebreak 규칙 필요(예: 참여 경기 수 → 소수픽 적중 수 → 제출 시각).

예측 마감 정확도

각 경기 킥오프 정시 자동 Lock. 마감 후 제출/수정 불가. 대량 동시 제출 트랜잭션 처리.

결과 정정·롤백

결과 오입력 시 수정 후 재계산 버튼으로 점수·랭킹 일괄 갱신(멱등).

어뷰징 방지

자동 배정+보상 구조라 다계정 5인 팀 차단 장치 필요(기존 계정 인증 재사용).

푸시 (선택 1종)

여력 시 "오늘 경기 미예측" 1종만. 어려우면 앱 내 배너로 대체.
