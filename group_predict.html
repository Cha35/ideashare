02

배경 & 설계 원칙

최우선 원칙은 "누구나 1초 만에 이해하고, 쉽게 참여"다. 이 기준으로 두 가지 함정을 의도적으로 피했다.

적중률(%) → 점수 누적

적중률 기반은 "많이 참여한 사람이 손해" 보는 역설이 생기고 체리피킹을 유발. 그래서 맞히면 점수가 쌓이는 누적 방식으로.

전체 노출 → 라운드별 노출

경기를 한 번에 다 깔면 인지 부하·원앤던으로 재방문이 죽음. 그날/그 라운드 경기만 노출해 재방문 루프를 만든다.

03

핵심 구조 확정 방향

처음 못 박은 "그룹이 주인공" 원칙 그대로

A 그룹이 폴리볼과 대결

유저는 그룹(팀)을 이뤄 참여한다. 상대는 "폴리볼"이라는 고정 기준선. 한 문장으로: "우리 그룹이 폴리볼을 이겨라."

B 판정 방식 — B안 채택

폴리볼은 1세트 점수. 멤버 각자가 폴리볼과 점수를 1:1 비교하고, 그룹 안에서 과반이 폴리볼을 이기면 그룹 통과. 합산 비교가 아니라서 인원수·평균·분모 문제가 발생하지 않는다.

C 그룹 5인 고정 + 자동 매칭

모든 그룹을 5인으로 통일. 친구가 모자라면 자동 배정으로 채운다. 자동 그룹 생성은 필수, 친구 초대는 강력 추천(2순위 개발).

D 보상

그룹이 폴리볼을 이기면 그 그룹 참여자 전원 보상 자격. 그 안에서 개인 점수 순위로 차등 지급(상세는 04 참고).

E 폴리볼 픽은 공개

폴리볼이 각 경기에서 무엇을 골랐는지·맞았는지를 전부 공개한다. "내가 폴리볼보다 안목이 좋았다"는 쾌감이 핵심. 단, 내부 점수 보정 같은 계산식은 비공개.

F 그룹전 ≠ 개인 랭킹전

둘은 별개 콘텐츠. 그룹전은 "팀으로 폴리볼 이기기", 개인 랭킹전은 "내 안목 증명". 한 번 찍으면 양쪽에 점수가 따로 쌓이게.

04

보상 지급 구조 구조 결정 필요

'볼' 지급량은 추후. 여기선 "누가·어떤 단계로 받는가"의 뼈대만
대상조건보상 형태(안)
그룹 통과 · 개인 1위그룹이 폴리볼 격파 + 그룹 내 1등최상위 보상 (예: 확정 직관 티켓 또는 상위 응모권)
그룹 통과 · 상위 순위그룹 격파 + 2~3등볼 차등 + 응모권
그룹 통과 · 전원그룹 격파 + 최소 참여 충족기본 볼
격파 실패 그룹 참여자최소 참여 충족검토 — 참여 위로 볼(이탈 방지) 여부

차등 단계

그룹 내 순위 차등을 몇 단계로? 1등 단독 특별 보상 / 1·2·3등 차등 / 전원 비례 — 단계 수가 동기와 직결.

확정 vs 추첨 혼합

볼은 확정 지급으로, 큰 상(직관 티켓 등)은 응모권 추첨으로. 이긴 그룹이 많아도 예산 통제가 가능한 구조.

예산 관점: 확정 지급(볼)은 이긴 그룹 수에 비례해 늘어난다. 폴리볼 픽 난이도(게이트가 얼마나 빡센가)가 곧 "이긴 그룹 수 → 보상 총량"을 좌우하므로, 06의 픽 난이도와 함께 묶어서 봐야 함.

폴리볼(상대) 픽을 무엇으로? 핵심 미결

배당 API는 사용하지 않기로 확정. 대안 검토 중
관점 전환: 폴리볼 픽의 목표는 "정확한 예측"이 아니라 "공정하고 설명 가능한 기준선"이다. 폴리볼이 강팀 위주로 안전하게 갈수록, 이변을 맞힌 유저의 쾌감이 커진다. 그래서 정교함보다 "유저가 넘을 만한 난이도냐"가 진짜 판단 기준 → 과거 경기로 적중률을 시뮬레이션해 결정해야 함.
FIFA 랭킹 / ELO 기반
  • ＋ 무료·공개, 빵꾸 없이 100% 자동, "랭킹 기반"으로 한 문장 설명 가능
  • － 홈 어드밴티지·최근 폼·부상·대진 운 등 변수를 못 잡음(단순함)
임직원 다수결 검토
  • ＋ 근거 설명 불필요("직원들이 찍었다"), 사람 스토리가 기사에 따뜻함
  • ＋ 다수결로 1세트 픽 확정 → B안에 부합. 빵꾸 경기는 랭킹 디폴트로 보완
  • － 참여 일관성·운영 손이 듦(새벽 경기 등 펑크 관리 필요)
외부 예측(Opta 등) 수치를 그대로/임의조정해 사용 비추천
  • － 상업 서비스가 타사 모델 결과물을 복제 → 권리 분쟁 소지
  • － 임의 조정 시 "그 수치의 근거가 뭐냐"에 답할 수 없어 공정성이 흔들림
  • ＋ 단, 내부 검증용 참고(우리 기준선이 권위 모델과 얼마나 비슷한지)로는 유용
08

운영 규칙 & 엣지 케이스 규칙 결정 필요

빠지면 개발 단계에서 막히는 것들

★ 폴리볼 픽 공개 타이밍

킥오프 전에는 폴리볼 픽을 숨김(유저가 베끼는 것 방지), 마감 후 결과와 함께 공개. 대결이 성립하려면 반드시 필요한 규칙.

미참여자 처리

예측 0건 멤버는 보상 제외(최소 N경기 참여 조건). 단 과반 판정은 "참여자 기준"이라 비활성 멤버가 그룹 통과를 막지 않음.

동점 처리

멤버 점수 = 폴리볼 점수일 때 '격파'로 칠지 '미격파'로 칠지 규칙 필요. 그룹 내 순위 동점은 참여 경기 수 등으로 tiebreak.

그룹 결성·중도 합류

모집 기간, 라운드 중간 합류 허용 여부, 5인 미달 그룹의 자동 매칭 충원 시점을 정의.

어뷰징 방지

자동 매칭 + 보상 구조라 한 명이 다계정으로 5인 그룹을 꾸리는 어뷰징 차단 장치 필요(기기·인증 기준 등).

결과 알림

"폴리볼을 이겼는지" 결과·마감 임박 푸시로 재방문 루프 강화(운영 시 함께 설계).
