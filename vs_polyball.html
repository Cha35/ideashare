BP-00개요 · 컨셉방향 확정
핵심 방향 — "이기는 경쟁"이 아니라 "참여하는 도전". 재미와 참여 폭(더 많은 유저)을 우선하고, 이긴 소수에게 큰 보상이 몰리는 희소성 모델은 채택하지 않는다.
확정목적 및 포지셔닝
목적 — 월드컵 개인 랭킹전 참여 유저에게 재미와 추가 참여 동기 제공. 폴리볼 AI 예측과 유저의 픽을 대전 구도로 프레이밍.
포지셔닝 — 개인 랭킹전 위에 얹는 이벤트 레이어. 별도 기능이 아니라 기존 픽 경험에 "AI와의 대결"을 부착하는 형태.
폭의 엔진은 보상이 아니라 재미 — 유저를 움직이는 1차 동력은 "AI를 이긴다"는 감정이며, 보상은 이를 거드는 양념 수준으로 둔다.
확정운영 단위
개인 랭킹전 각 회차별 독립 진행. 회차 시작 시 순위·대결 초기화.
기간: 월드컵 개인 랭킹전 전체 (중도 중단 없음).
자동 참가 — 개인 랭킹전 픽 = 폴리볼 대결 참가. 별도 진입·신청 없음.
BP-01판정 · 점수 규칙확정
확정점수 체계 — 유저·폴리볼 동일 적용
상황획득 점수
기본 적중100
30% 미만 선택 후 적중150
20% 미만 선택 후 적중180
10% 미만 선택 후 적중 (contrarian)200
확정폴리볼 점수 출처
픽은 사전 고정 — 정배(favorite) 기반 시뮬레이션 모델(Poisson)로 회차 시작 전 폴리볼의 픽을 확정.
점수는 사후 정산 — 실제 경기 결과로 적중 여부를 계산해 정산 시점에 폴리볼 점수를 확정. (사전 "최종 점수" 확정 아님)
MD1은 실제 결과 기반, MD2·MD3는 예측 기반으로 화면에 라벨 표기.
확정승패 판정
유저 점수 ≥ 폴리볼 점수 → 유저 승 (보상 대상).
동점은 승으로 처리 — 폴리볼과 동점인 유저도 보상 대상에 포함.
BP-02보상구조 확정 · 값/재화 TBD
단순 정액. 분배형(100개 N분의 1)과 총량 캡은 폐기. "폴리볼을 이기면 정액, 못 이기면 0"의 가장 단순한 형태.
확정지급 구조
폴리볼을 이기면(동점 포함) 소액 정액 지급. 못 이기면 0.
참여 기본 보상은 별도로 주지 않음 — 개인 랭킹전 자체가 이미 "예측 마켓 참여 + 적중 보상"을 제공하므로 중복. 폴리볼을 이겨라 보상은 그 위에 얹는 재미용 추가분.
못 이긴 유저도 손해가 없음 — 랭킹전 기본 보상은 정상 수령하기 때문.
지급 시점 — 회차 정산 시 순위 보상과 함께 지급.
TBD · 블로커보상 재화
현재 개인 랭킹전 순위 보상은 네이버페이 포인트(1만/1천원)로 지급된다. 폴리볼을 이겨라 추가 보상의 재화가 이와 정합되어야 한다. 개발 착수 전 확정 필요.

소액 N페이재화 일관 + 규모만 축소비용 통제선 별도 설계 필요

정액 값 X = TBD — 보상 재화 확정 후, 해당 재화의 실제 가치를 기준으로 산정.
인플레 체크포인트 — 정액 구조상 이변 많은 회차엔 거의 전원이 X를 받을 수 있음. "보상 대상 전원 × X"의 최대 살포량이 감당 가능한 선에서 X를 끊어야 함(특히 무료 재화일 때 응모권 가치 희석 주의).
BP-03폴리볼 페르소나 · 카피방향 확정 · 카피 안
톤 = 공식 톤 기반 + 살짝 도발. "건방진 캐릭터"가 아니라 "자신감 있는 공식 AI가 가볍게 약 올리는" 선. 픽 근거 공개로 "어디 보자" 호기심 유발. 인앱 카피는 해요체.

확정노출 규칙
대결 카드 위치 — 개인 랭킹전 "내 예측 참여/적중/순위" 현황 카드 바로 아래.
랭킹 인라인 — 폴리볼을 점수 위치에 한 줄로 삽입하되, 유저 순위 번호에는 미반영(표시 순위 ≠ 실제 순위). 폴리볼 행은 🤖 + "순위 미집계"로 표기.
폴리볼의 픽 화면 — 대결 카드 진입. 경기별 폴리볼 픽·근거 vs 내 픽 비교. MD1 실제 결과 / MD2·MD3 예측 기반 라벨.
자동 참가 — 승부예측 탭은 기존 흐름 그대로. 픽 = 대결 자동 참가.
BP-05정산 · 업데이트확정
확정수기 정산
정산은 수기. 폴리볼 점수·승패·보상을 모두 정산 시점에 확정·지급.
유저는 정산 후 결과를 확인.
폐기실시간 처리 제거
매 경기 직후 실시간 점수·순위 갱신 폐기.
상위 진입/탈락 실시간 알림, 축하 애니메이션 폐기.
→ 초기 스테이지 개발 부담 제거 목적.
BP-06난이도 · 운영확정 · 주의
확정난이도는 구조가 자연 조절
별도 난이도 조정 안 함. 정배 기반 모델 + 이번 대회 이변 多 + contrarian 보너스 조합이 폴리볼을 자연스럽게 만만하게 만들어 참여 폭을 받쳐줌.
폴리볼은 정배(고확률)만 골라 보너스를 거의 못 받고 100점에 묶임 → 유저가 이변(저확률)을 맞히면 한 경기로 격차를 크게 벌림.
운영 가이드픽 세팅 주의
폴리볼 픽을 과하게 강하게 짜지 말 것 — 중위 유저가 절반쯤 이길 수 있어야 다수가 도전.
이변 적은 무난한 회차엔 폴리볼이 강해져 이기기 어려워질 수 있음 → 회차 간 편차는 감수(재미 양념 보상이라 영향 제한적).
